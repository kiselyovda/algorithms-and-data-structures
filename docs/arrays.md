# Массивы

Массив представляет из себя непрерывную область памяти заданного размера.
Данные которые он хранит в себе должны быть однотипными.
Доступ по индексу массива происходит за O (1).

## Структура массива

- size — количество элементов в массиве
- capacity — количество элементов, которое он может в себя вместить (size<=capacity)
- type — тип данных

## Операции

- get (index) — получение элемента по индексу O (1)
- append () — вставка в конец O (1)
- remove (index) — удаление из массива O (n)
